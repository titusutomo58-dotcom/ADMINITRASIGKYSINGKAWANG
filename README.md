# ADMINITRASIGKYSINGKAWANG
GKY Singkawang adalah komunitas orang percaya yang berpusat pada Kristus dan berlandaskan kebenaran Firman Tuhan, hadir untuk beribadah, bertumbuh dalam iman, hidup dalam kasih, serta mengambil bagian dalam pelayanan dan pemberitaan Injil sebagai Gereja yang mulia dan misioner.
